Vitae 简历与岗位助手 · Windows 便携版

开始使用
1. 将压缩包完整解压到一个可写入的文件夹，不要在压缩包内直接运行。
2. 双击 Vitae.exe，稍等片刻，默认浏览器会自动打开应用。
   如果浏览器没有打开，请访问 http://127.0.0.1:8000/ 。
3. 点击侧栏“设置 → 新建配置”，选择 DeepSeek 或自定义服务商，填写自己的 API Key。
   使用 DeepSeek 时：API 地址 https://api.deepseek.com，模型 deepseek-flash。
4. 点击“测试连接”，成功后点击“保存配置”。如需三个 AI 功能都使用这份配置，
   请在配置列表右侧分别勾选三个功能。测试成功不等于已经保存。
5. 导入或填写简历，确认内容，再选择目标岗位，查看匹配与优化建议。

运行要求
- Windows 10 / 11，64 位。无需安装 Python、Node.js、Git 或开发环境。
- 本地页面和数据保存在电脑上；调用 AI 服务及同步在线岗位需要联网。
- API Key 由你向服务商申请，调用费用由对应服务商收取。
- 必须保留 EXE 旁的 _internal 文件夹，不能只复制一个 EXE。

保存与退出
- 简历和岗位数据位于 data 文件夹；AI 设置位于 .runtime 文件夹。
- 配置保留在本机，关闭浏览器标签页不会停止本地服务。
- 正常退出请点击侧栏退出按钮，或设置中的“更多操作 → 保存并退出”。
- 迁移电脑或升级时，请先退出旧版本，并备份 data、.runtime 以及自行创建的 .env。
  将这些用户文件复制到新版 EXE 旁即可保留数据。不要用安装包覆盖自己的备份。
- 如需分享程序，请分享原始下载压缩包，不要分享已使用目录中的用户文件。

无法启动时
- 如果提示 8000 端口被占用，先关闭已运行的本应用或其他占用该端口的服务。
- 保留启动窗口中的错误信息，方便定位问题。
- .env.example 仅供熟悉环境变量的用户选用；普通使用无需手动创建 .env。
