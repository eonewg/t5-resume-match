# 岗位工作区与快速选择验证

2026-09-10，基于当前 `refactor/frontend-product-shell` 工作区实现。

## 用户需求与实现

- 岗位创建独立为 `#/jobs/new`：左侧粘贴、文档提取、截图导入，右侧基本信息、职责与要求、技能与工具分组；支持完整手动填写。
- `#/jobs` 专注已保存岗位库。简历与岗位的编辑/创建、资料库入口分别放在各自工作区内部，不占侧栏独立菜单。
- 匹配和优化使用可搜索的简历、岗位选择器，支持关键字过滤、键盘与鼠标选择、无结果提示。切换仅改变选择与已有结果展示，不自动发起分析。
- 文档提取和 AI 识别分开调用；AI 返回草稿不保存，保留手动字段与有意清空，原文独立备查。跨路由保留草稿，明确保存并重新读取后选中，读取失败只重试读取。
