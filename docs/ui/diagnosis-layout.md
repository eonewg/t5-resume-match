# AI 优化的表达与布局（2026-09-10）

用户反馈：左右目录布局产生大量留白；随后指出经历被拆成情境、任务、行动、结果，表达机械，“补充与核实”没有明确用途。

## 当前行为

- 经历表达保留紧凑索引和原文/建议对照。STAR 用于模型内部分析，生成结果是自然简历语句，不硬凑四个部分；原句清楚时可以保留。
- 缺少信息时，只在对应经历的修改说明里提出具体问题。建议正文不插入待补充占位符，不为润色推断新事实。旧结果仅移除可识别的四段式标签，原文、数字和已有待补充标记保留；自然语言质量的更新需要用户重新生成。
- 岗位重点直接列出建议。相关技能放在该分类底部的折叠区域，解释已用过的技能可补实际案例，未用过的可作为学习方向；该清单不判定掌握或缺失。
- 取消“补充与核实”主分类，已有提醒收进默认折叠的“修改前的补充提示”，没有提醒就不显示。其他未知格式仍按纯文本完整保留。
- 新提示词要求提醒只指出具体冲突、职责归属或过强措辞；普通描述不详细由经历说明和岗位建议处理。内部 risks 数组允许为空，仍保留上限及原文/数字校验；过滤不合规改写时仍能追加保护提示。

公共 API 字段、评分、简历保存方式不变；分类和折叠切换不会调用模型或写入简历。模型提示版本更新为 d-v4-natural-rewrite，进入既有缓存键。

## 验证与限制

- 诊断模块和公共接口回归 259 项通过；前端构建、101 项 Node/React 回归通过。回归覆盖旧结果、未知文本、仅提示/仅关键词响应、内容完整性及没有自动写入。
- 隔离数据库和明确合成响应在 1280、1440、1920px 验证两类导航、默认折叠、展开后完整内容、无横向溢出和无额外模型请求。截图保留在本地 `.verification/react-product-shell/flow/diagnosis-layout/`；该验证不代表真实模型质量。
- 两次 deepseek-flash 合成样本调用，无用户简历或数据库写入，每次限一次请求。第一次 4.98 秒，格式正确但人工发现“课程维度”“缩小范围”超出输入依据；收紧等价改写约束后，第二次 3.78 秒，输出自然语句、没有四段式标签或正文占位符，补充问题指向清洗规则。原文/数字保护通过。样本证据分别保存在本地 natural-diagnosis-first-review.json 和 natural-diagnosis-live.json，不能据此保证所有未来输出的语义质量。

本地服务已加载更新，/health 与 /ready 均为 200，首页引用最新构建。当前分支为 refactor/frontend-product-shell；提交与推送仍待此前自动审批要求的分支确认。


## 岗位建议的阅读改进

后续截图显示每条建议均以“岗位要求”开头，真正修改动作埋在长段落中。提示版本更新为 `d-v5-action-first`：每个岗位建议字符串首行直接写具体动作，第二段解释经历和岗位依据；合并同类建议，条件与动作写在一起。公共 suggestions 字符串数组不变。

页面用紧凑的可展开条目显示动作，展开后读取完整依据。旧结果从原有语句提取建议段作预览，完整正文保留；条件出现在动作之前时不裁掉条件。修复 JD 转写导致的“岗位要求 要求”。不调用模型生成预览，不更改原文、数字或持久化内容。

三种桌面宽度验证 10 条长建议的默认折叠、展开后完整内容与无横向溢出。最新合成实测 2.92 秒返回两条具体动作标题及换行依据，无四段式标签、正文占位符或通用风险提醒。该样本不代表所有未来输出质量。
