# Level 3 分析总览对齐（2026-09-10）

依据 `T5_REQUIREMENTS_MATRIX.md` 第 4 节及用户提供的课程原要求：聚合已录入 JD，输出技能词云、岗位薪资分布、岗位技能要求分布及职业规划参考。

## 本次差距与改动

此前已有词云、薪资直方图和技能频率统计，但默认仅选 `source_type=real`，手动或截图录入且尚未标明来源的岗位会被排除。主入口突出外部同步，逐岗位技能只以明细表展示，缺少把三项输出组织起来的总览。

- 默认请求无来源限制的 `/api/v1/analytics`，聚合已保存 JD。真实、课程、合成及未知来源计数继续展示；Mock 状态沿用接口。来源与自定义日期筛选仍可用。
- 默认进入「分析总览」，同时显示热门技能词云、分币种/周期薪资直方图、逐岗位技能要求矩阵及基于频次的职业准备参考。原技能、薪资、岗位来源主题保留。
- 技能矩阵每页 8 个岗位，支持搜索与翻页，列为当前筛选前 10 项技能。深色代表已确认或识别到的要求；未识别不等于不要求。沿用后端既有技能统计，不重新解析原文。
- 「不限日期」「近 30 天采集」「近 90 天采集」直接应用同一个后端日期筛选。按本地日历计算含今天的范围；采集日期不冒充发布日期，无日期岗位只进入不限日期分析。
- 外部来源同步收进「补充岗位数据」，仍为显式、手动操作；分析无需先联网同步。薪资未知值不填零，币种/周期不混算。
- 去掉目标岗位与历史简历页面根容器的多余浅色边框，保留内部内容卡片。

## 验证与边界

前端 72 项控制器/API 测试、60 项 React 交互测试通过，TypeScript 与 Vite 构建通过；Analytics 后端 18 项既有测试通过。新增覆盖默认全库请求、近期日期/闰年边界、总览三图、薪资单位切换和技能矩阵搜索分页。

## 薪资明细浏览调整

按用户反馈取消逐条勾选与另开对比区，改为按岗位名称粗分方向，默认展示当前币种/周期中数量最多的一组，直接绘制招聘薪资区间。每页 6 个岗位，支持方向切换、组内搜索和排序；同方向跨页/搜索保持统一刻度，不混合币种或计薪周期。分组仅用于界面浏览，不写回 JD，也不把不同资历或职责视为相同岗位。前端 72 项控制器/API 和 60 项 React 测试及构建通过，覆盖无勾选直接出图、分组、搜索、分页、稳定刻度和单位切换。
