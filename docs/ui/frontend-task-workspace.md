# T5 前端任务工作区重构

2026-09-10，分支 `refactor/frontend-product-shell`，基线 `94d572b`。

本次按用户要求重写前端展示层。设计依据是当前 T5 功能、内容与本次反馈；未检索或参考其他项目、竞品或历史视觉方案。用户自行进行视觉验收，本轮没有运行浏览器截图、视觉自评或视觉迭代。

## 页面组织

| 页面 | 新组织方式 |
| --- | --- |
| 全局导航 | 文本导航按任务分组，历史版本从属于简历，市场洞察单独放置；去掉重复页眉与全局编号步骤条。服务连接和 Mock 说明保留在导航底部。 |
| Home | 下一步入口与准备状态并列，当前简历和岗位按内容行展示；移除进度卡和编号块。 |
| Resume | 原文导入区与连续编辑区并排；紧凑文件拖入入口、字段定位、逐项保护状态、确认保存操作。 |
| Resume History | 版本表格、本页内容搜索、经历预览、行内打开与删除；仍可分页和清空全部。 |
| Jobs | 岗位搜索列表与完整要求并排；选择岗位后阅读技能、工具、原文、来源，再明确发起匹配；新增表单在阅读区展开。 |
| Matching | 分数与结论在前，评分依据作为阅读主体，已体现与待补充技能作为旁侧索引；保留全部依据的展开入口。 |
| AI Optimization | 按经历表达、岗位重点、补充与核实分类，索引选择单条完整建议；原文、建议和理由对照阅读，然后返回简历修改。相同建议字符串去重展示。 |
| Analytics | 样本范围、技能分布、分组薪资和来源明细分别组织；去掉统一指标卡，词云和完整表格按需展开。 |

基础样式集中在 `frontend/src/styles.css`，各页面布局在 `frontend/src/workspaces.css`。删除七份旧样式及其覆盖链；没有增加依赖。层级主要使用字体、空间和内容顺序，边界用于输入控件、版本表格和确有必要的操作分隔。默认次要动作采用文本表现。

## 行为与边界

- 保留当前 API、公共 workspace、各模块 controller。没有改 FastAPI、数据库、AI Prompt、匹配算法或 Windows EXE 打包链。
- 简历上传、粘贴、AI 识别、手动恢复、原文保留、字段保护、显式采用建议、确认保存后 GET 重读，以及只重试 GET 的恢复路径保留。
- 历史删除仍清理选择和关联结果，保留未保存草稿；全部清空仍跨分页生效。本页搜索不会改变当前选择或缩小全部清空的范围。
- 岗位搜索不会改变选择；选择或新增岗位仍使旧配对结果失效。示例只填入表单，不自动保存、匹配或调用优化。
- 优化展示保留原文、数字、待核实标记和完整理由。切换建议不会采用、改写或保存简历。
- Mock 标识、错误反馈、重试、请求取消与过期响应保护保留。
