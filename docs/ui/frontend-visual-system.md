## 视觉规则

- 蓝灰色工作区承托白色主要工作面板；蓝色统一主按钮、当前导航、选中项和重点数据。绿色用于已就绪和已体现技能，琥珀色用于待补充与 Mock 来源标识。
- 主要工作面板使用 14–20px 圆角和轻阴影，输入框与控件使用 6–10px 圆角。段落、普通字段和说明不逐项套卡片。
- 标题、正文、标签、辅助文字和数字使用不同字号、字重与间距。使用本机无衬线字体栈，不引入字体下载或新依赖。
- 主操作为蓝色实心按钮，次操作为浅底描边按钮，辅助和危险操作使用轻按钮；提供 hover、按下、禁用与键盘焦点表现。选中项在 hover 时保持选中背景，减少动态效果偏好仍有效。

## 页面应用

| 页面 | 视觉处理 |
| --- | --- |
| 全局导航 | 白色侧栏、品牌色标记、辅助线性图标、当前项背景和侧边标识；位置与导航分组不变。 |
| Home | 下一步与准备状态组成重点工作区域；当前简历和岗位在一个连续白色区域内按行呈现。 |
| Resume | 浅蓝灰原文导入面板与白色编辑面板分开；上传入口、字段定位、字段状态和保存区有明确层级。 |
| History | 浅底工具区与白色版本表；当前版本整行浅蓝及侧边标识，其他行提供 hover。 |
| Jobs | 浅底岗位集合与白色阅读面板；当前岗位有选中边线和深度，原文使用次级 surface。 |
| Matching | 浅色结论区突出分数与岗位；依据阅读区和技能汇总采用独立工作面板，技能状态分别着色。 |
| AI Optimization | 建议分类采用分段控件，索引选中态与阅读面板分离；原文、建议使用不同浅底，理由保持普通文本。 |
| Analytics | 样本概览、主图表和薪资区域有选择地使用 surface；筛选为浅底工具区，说明与来源维持内容阅读方式。 |
