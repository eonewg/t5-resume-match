## 规则与解释

`evidence_filter.py` 对完整句段做轻量规则过滤，然后才分 80 字符向量片段。
否定/未具备（不要求、无需、没有、从未、not/never 等）、学习意向（正在学习、希望、计划、currently learning 等）不作为语义能力证据。
JD 福利/公司介绍句段也不参与语义评分；新解析 JD 的关键词提取复用同一过滤，原文原样保留。
过滤发生在切片前，长否定句不会因切片而漏出未带否定词的尾部。
结果解释给出过滤数量与类型；全部过滤时明确降级到 keyword-only，绝不伪造语义成功。
已有结构化 skills 是用户/上游确认事实；不改写已有 matched/missing 算法，不根据相似度移除 gap。
旧记录如果存在原文与结构化 skills 冲突，需要重新解析或人工确认；本轮不擅自修订公共存储。
