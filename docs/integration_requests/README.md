# 公共层集成请求

模块负责人将请求保存为 `成员-主题.md`，说明公开接口、期望字段、原因、调用示例、依赖和验证方式。公共 Schema、路由、数据库或根配置的变更与 A 协调。A 可在此记录自己的跨模块公共设计决定。

向量请求必须说明对象、embedding 模型、维度、距离、评分方式和查询需求；A 负责 PostgreSQL/pgvector 字段、索引、迁移和 adapter。薪资/来源/时间字段由 A/C/E 对齐后纳入公共契约，不在业务模块另造共享模型。

A 追加处理结论与验证证据，接口变化同步 [API 契约](../api-contract.md)。缺少模块可继续用明确标记的 Mock，但真实验收需公开入口、测试和样例。
