本报告现包含 **2026-09-09 用户提供的人工体验记录**，以及 2026-09-08 的公开资料调研。两类证据分别标注；人工记录原文见 [体验记录](final/competitor-human-notes.md)。A 归档并对照当前实现，未声称自行完成这些操作。

## BOSS直聘：2026-09-09 人工体验

用户实际完成在线简历查看、简历诊断与职位推荐/匹配流程。设备与版本未提供。

| 环节 | 体验观察 |
| --- | --- |
| 简历与导入入口 | 在线简历结构化编辑；可见已有简历导入、附件导出能力及内容缺失提醒 |
| 诊断 | 实际体验简历诊断，与简历完善流程相接 |
| 岗位推荐/匹配 | 根据求职意向推荐相关岗位；列表呈现薪资、经验、学历、技能标签 |
| 结果与下一步 | 进入岗位可查看完整 JD，存在收藏和招聘者沟通入口；未把入口观察写成已发送消息 |

**做得好的地方：** 简历完善、推荐和沟通衔接顺畅，岗位与技能信息直接，求职路径短。这是用户对本次体验的判断，不是平台整体效果指标。

**明显问题：** 本次推荐路径未明显显示个人与单个岗位的综合匹配度，也未集中说明已满足要求、能力缺口与推荐原因。结论限定于体验路径，不推断产品其他页面没有相关能力。

**与 T5 的差异与设计取舍：** BOSS 串联招聘机会与沟通；T5 聚焦已录入、已选择 JD 的可解释分析。T5 已采用简短岗位展示，并拆分后端真实分数、已匹配能力、待补能力和可展开依据；保留来源与薪资未知值。未采用直聊、投递、收藏招聘库、模板商城或简历附件导出。本次只对照既有设计，不新增系统功能，也不把事后观察写成原先开发的动机。

## 智联招聘：2026-09-09 人工体验

用户已登录网页版，实际体验在线简历、AI 简历优化和职位推荐。

| 环节 | 体验观察 |
| --- | --- |
| 简历与导入入口 | 结构化编辑，支持附件上传、预览、下载和模板，并提示待完善项 |
| 诊断/优化 | 实际体验 AI 简历优化，与简历编辑放在同一求职准备流程中 |
| 岗位推荐/匹配 | 结合求职意向，按 Python、深度学习、算法工程师、全栈工程师等方向分类展示 |
| 结果与下一步 | 岗位卡片含公司、薪资、学历、校招等信息，存在直接投递入口；不声称已实际投递 |

**做得好的地方：** 编辑与 AI 优化能力较完整，推荐与求职意向关联明确，岗位信息简洁、投递路径短。

**明显问题：** 本次推荐主要呈现一批岗位，未明显集中解释个人简历与单个岗位的匹配理由、优势和缺口；简历页信息密度较高。这是具体路径与界面的体验判断，不代表所有产品端的能力范围。

**与 T5 的差异与设计取舍：** 智联提供岗位发现和投递链路；T5 围绕用户选定目标进行“目标岗位 → 匹配分析 → 简历优化”，显示分数、覆盖能力、缺口与改进建议。已采用目标驱动、简洁岗位信息与人工核实的设计方向，保持未掌握技能不作既有事实、未知薪资不填零。未采用自动推荐招聘库、代聊、投递与提醒；不把“根据求职目标推荐岗位”的启示误写成 T5 已实现的功能。

## 公开资料背景（2026-09-08）

BOSS [官方简历产品页](https://cv.zhipin.com/)介绍在线编辑、AI 生成、匹配度/短板诊断与同步；[模板页](https://cv.zhipin.com/job/j2/)提供导入入口。智联[官方功能说明](https://rd6.zhaopin.com/aboutus/legal/privacy)介绍附件解析和 AI 改简历；[求职 AI 产品页](https://ai.zhaopin.com/)介绍岗位适配、沟通、追踪和关键事项确认，同时有预约/内测信息。公开能力不等于每个账号或本次页面都可使用，与人工体验中“未明显看到解释”并不矛盾。

此前用户提供的公开评论摘要涉及岗位真实性、薪资/停招信息、推荐质量、招聘方反馈和隐私等主题，但未附原始评论链接；仅作待核实线索，不当作本次人工复现问题或普遍缺陷。历史工具访问失败只属于 2026-09-08 的访问记录，不能继续作为“人工体验未完成”的当前结论。
