## 4. 逐维度小结

- 简历制作：两大平台的公开资料均未展示强编辑体验；第三方简历工具生态活跃，说明**结构化编辑 + 导出**是普遍形态，T5 的结构化简历编辑器有对应价值。[A/B]
- 岗位匹配：平台以推荐流为主，公开资料中**均未见到可解释的技能 gap 清单**形态，这是 T5 差异化机会。[A/B，结论限于检索所见，非穷尽调研]
- AI 诊断：智联已有官方 AI 功能宣传，说明方向与市场一致；T5 需在"可解释 + 不编造事实"上建立差异。[A-标题/B]
