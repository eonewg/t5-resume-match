# 招聘平台竞品调研报告

调研日期：2026-09-08。**本节为公开资料与用户反馈调研，不是登录后的人工实测。** 用户提供两款平台的调研摘要，A 补充核实可访问的官方产品说明。功能宣介不等于实测效果，官网引述的用户感言也不是本项目的独立访谈。

## BOSS直聘

公开资料对应的核心路径为简历导入/在线编辑 → 目标岗位匹配度和短板诊断 → 定向简历生成 → 预览、导出或同步。官方[简历首页](https://cv.zhipin.com/)说明编辑、AI 生成、匹配度诊断和同步能力，[模板页](https://cv.zhipin.com/job/j2/)可见导入入口。本次没有在登录账户中验证文件格式、解析准确性、付费范围或完整结果。（官网能力摘要，非操作记录。）

从界面说明可见的长处是把编辑、指导和输出串联，便于围绕岗位准备材料；这是基于公开流程的设计判断。用户提供的调研还肯定直聊和求职进度反馈，但未提供该部分具体体验记录，不能写作 A 已验证发送/已读状态。

用户提供的公开反馈摘要提到岗位描述与薪资不清晰、实际岗位与描述不符、已读不回、投诉反馈不透明。这些是**未附原始评论链接的反馈主题**，本轮未独立核验发生频率或具体案例；不称作普遍事实、已复现缺陷或全部归因于平台。

与 T5 的差异：BOSS 属于招聘服务和简历产品，公开流程包含简历输出/同步；T5 当前只做已录入履历与 JD 的确认、分析、优化和样本观察，不提供招聘者沟通、简历 PDF 导出或投递状态。

本项目已采用的思路是原文与可编辑内容并置、目标岗位驱动优化，以及结果展示时解释缺口；现有实现额外保留字段确认、保存重读、来源与未知值。此处为事后对照，不能声称此前从未体验的功能直接启发了开发。未采用模板商城、招聘者直聊、投递和简历同步；它们超出本课程当前范围，本轮不新增。

## 智联招聘

公开材料对应的核心路径为附件导入/完善简历 → 岗位筛选与匹配 → 按岗位调整经历表达 → 查看建议或跟进事项。官方[隐私政策中的功能说明](https://rd6.zhaopin.com/aboutus/legal/privacy)提及附件解析、在线简历及 AI 改简历；[求职 AI 产品页](https://ai.zhaopin.com/)介绍岗位匹配、JD 适配、沟通和进度追踪，并说明关键事项先确认。该产品页还显示预约/内测信息，不能据此宣称全部账号当前已能使用所有能力。

公开设计的长处是把岗位要求和候选人经历联系起来，提示重点与待确认事项；这是流程判断，不是实测准确率。产品页提供前后表达示例，但示例不能证明所有输出均忠实、不增补事实或提升求职结果。

用户提供的公开反馈摘要提到推荐不精准、分类混乱、停招状态不明显、招聘方无反馈，以及岗位真实性和隐私控制担忧。因未附原始评论链接，保留为**待核实反馈主题**；未计算投诉频率、未复现，也不作产品事实结论。

与 T5 的差异：智联公开说明覆盖招聘机会筛选、沟通和跟进；T5 聚焦用户已选 JD 的关键词覆盖与建议，未实现自动检索招聘库、代聊、投递或面试提醒。T5 分数也不代表招聘平台的岗位推荐能力。

本项目已采用相同方向的设计是“目标岗位 → 匹配分析 → 简历优化”，同时要求未证明技能保持待核实、未知薪资不填零、建议不能自动写回事实字段。未采用自动代聊、投递计划和通知，因为需要外部招聘工作流且不属于当前交付；不为本次调研再改系统。
