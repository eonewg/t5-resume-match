# 截图导入验证（2026-09-10）

实现截图识别独立模型分配、简历上传预览、岗位截图预览及结构化编辑。公开 provider 仍为四个业务模块；新增字段保存在现有 JSON payload，无数据库迁移。

真实调用使用用户已配置的 DeepSeek `deepseek-flash`：合成岗位与合成简历各一次均通过；用户指定的 Python 岗位截图测试两次。第一次将「大数据环境」漏字为「大数环境」，随后加强逐行复核提示；第二次正确转录该句，保留「3–5年」与正文「5年以上」的差异，识别出北京、本科、15–20K·14薪、职责与加分项。截图未显示公司，结果为空。单张截图成功不能证明所有截图转录准确，产品保留人工编辑与确认。

测试未保存用户截图到仓库，也未向真实简历/岗位数据库写入记录。原始调用结果仅保存在忽略的本机验证目录；共享文档不包含截图全文或密钥。按用户要求未进行视觉巡检。

离线测试覆盖图片内容校验、大小限制、Chat/Responses 图片载荷、拒绝/截断/无效 JSON、预览不写库、岗位字段修改后保存、独立模型配置持久化与前端预览后确认保存。现有文档上传与受保护简历字段回归保留。

最终验证：后端 683 passed、40 skipped（需要显式环境的项目），前端 70 项控制器/API 测试与 56 项 React 交互测试通过，TypeScript、Vite 生产构建、Ruff 和 diff 检查通过。没有把此结果当作已重新构建或发布 Windows EXE；此前 v1.2.0 草稿包未包含本功能。
