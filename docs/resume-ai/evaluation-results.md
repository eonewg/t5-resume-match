## 暴露的问题

1. **技能数组粒度不稳定。** student-01 将技能合并为三个长数组元素；混排样本出现 `Python, SQL, TypeScript, FastAPI, PostgreSQL, Git, Docker, Linux` 单项。内容有依据，但守卫按原文逗号分句，不能匹配整项；Prompt/schema 与守卫接受范围不一致。
2. **复合技能误拒。** student-02 的 `Operator, memory access, communication, and performance bottleneck analysis` 在原文完整存在，仍被拒。student-03 的 `brightfield microscopy video data analysis` 对应原文明示的分析行为，但文字匹配不接受这种技能表达。
3. **执行计划被当作学习计划。** 复杂中文原文的 `MySQL、PostgreSQL（索引原理、事务隔离、执行计划分析）` 是已掌握技术，守卫因“计划”一词拒绝 MySQL/PostgreSQL。
4. **项目内技术漏提取。** 模型能保留项目，却没有稳定将其中明确使用的技术并入 skills，复杂样本 recall 不足。
